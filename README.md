# 🤖 Checkpoint 1: Construcción de Chatbot (IA + Agile)

El repositorio contiene todo el progreso técnico y los ejercicios completados desde los fundamentos de NLP hasta el módulo de **Reranking (incluido)**, sentando las bases para el RAG de nuestro chatbot.

## 📂 Estructura del Repositorio

He dividido el código en dos carpetas principales para separar la teoría de la práctica:
* `/notebooks`: Aquí están los cuadernos principales guiados de clase (del 00 al 07). Contienen la teoría, las pruebas de concepto y los laboratorios interactivos.
* `/exercises`: Contiene mis soluciones completas a los ejercicios propuestos para cada sesión (EX_00-07).
* `requirements.txt`: Todas las dependencias necesarias con sus versiones fijadas para que nada rompa al ejecutar.

* ## 🛠️ Instalación
Para que no haya problemas de compatibilidad, te recomiendo crear un entorno virtual e instalar las dependencias directamente:

pip install -r requirements.txt
